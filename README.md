# File-Handling-Project
A simple file management system (Create, Read, Update, Delete) built with Python and Streamlit — lets users manage text files through an interactive web UI.

📁 File Manager App

A beginner-friendly **CRUD (Create, Read, Update, Delete)** file management 
tool built with **Python** and **Streamlit**. It lets users create, view, 
edit, rename, and delete text files through a clean web interface — no 
command-line typing needed.

✨ Features
- **Create** — make a new text file with custom content
- **Read** — view the contents of any existing file
- **Update** — rename a file, append new content, or overwrite it entirely
- **Delete** — remove a file safely, with error handling

🛠️ Tech Stack
- Python 3
- Streamlit (for the UI)
- `pathlib` (for file system operations)

🚀 How to Run Locally
```bash
git clone https://github.com/YOUR-USERNAME/file-manager-app.git
cd file-manager-app
pip install -r requirements.txt
streamlit run file_manager_app.py
```
